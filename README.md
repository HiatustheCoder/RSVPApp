# RSVPApp

A .NET MAUI RSVP application for browsing events, viewing event details,
and managing invitations. The interface uses deep blue, white, and green.

## Features

- Log in using demo credentials or continue as a guest.
- Open the Create Account page with required-field validation.
- Browse All, Attending, and Hosting event lists.
- View sample event details and attendee lists.
- Open the Add Event page with form validation.
- Open an RSVP form with prefilled information for logged-in users
  and blank fields for guests.
- View pending and accepted invitations.
- Review past events.
- Log out and return to the login page.

## Running the App

1. Open the solution in Visual Studio with the .NET MAUI workload installed.
2. Allow NuGet packages to restore.
3. Select Windows Machine as the run target.
4. Build and run the application.
5. Log in with the demo credentials or select Continue as Guest.

## Current Limitations

The application currently demonstrates page navigation and input validation.
Accounts, events, and RSVPs are not saved. Events and invitation statuses
use hard-coded sample data. The MAUI bot image serves as a placeholder
for event pictures.
